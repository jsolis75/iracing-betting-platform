# Push to GitHub - Easy Method (GitHub Desktop)

Since Git command line isn't working yet, let's use GitHub Desktop - it's much easier!

## Step 1: Install GitHub Desktop

1. Download: https://desktop.github.com
2. Install and open it
3. Sign in with your GitHub account (or create one)

## Step 2: Add Your Project

1. In GitHub Desktop, click **File** → **Add Local Repository**
2. Click **Choose...** and navigate to:
   ```
   C:\Users\jsoli\.gemini\antigravity\scratch\iracing-betting-platform
   ```
3. Click **Add Repository**

If it says "This directory does not appear to be a Git repository":
- Click **Create a repository** instead
- Name: `iracing-betting-platform`
- Click **Create Repository**

## Step 3: Review Changes

You should see all your files listed in the "Changes" tab.

## Step 4: Make Initial Commit

1. In the bottom left, you'll see:
   - **Summary**: Type `Initial commit - iRacing betting platform`
   - **Description**: (optional) `Full-stack betting platform with Next.js frontend`
2. Click **Commit to main**

## Step 5: Publish to GitHub

1. Click **Publish repository** button at the top
2. Choose:
   - **Name**: `iracing-betting-platform`
   - **Description**: `Live betting platform for iRacing events`
   - **Keep this code private**: Your choice (uncheck for public)
3. Click **Publish Repository**

## Done! ✅

Your code is now on GitHub! You'll get a URL like:
```
https://github.com/YOUR_USERNAME/iracing-betting-platform
```
